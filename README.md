# 愤怒的小鸟复刻（Unity / C#）

基于 Unity 物理引擎的《愤怒的小鸟》玩法复刻，小组实训项目，负责程序与玩法设计。

## 功能

- 弹弓蓄力拖拽与抛物线飞行（物理引擎）
- 障碍物碰撞破坏、计分与胜负判定
- 章节选择、关卡选择与星级解锁 UI
- 暂停、音频等基础系统

## 技术要点

- 状态机管理「待机—蓄力—飞行—结算」全流程
- 继承 + 多态实现多鸟种技能（黄鸟 / 黑鸟 / 爆炸鸟，飞行中 / 落地技能）
- ScriptableObject（MapSO / GameSO）数据驱动配置关卡
